📖 Overview

The Invoice Manager provides a full REST API for programmatic access to all data. This allows you to integrate with other systems, automate invoice creation, receive payment notifications, and more.

Base URL: {{ request.host_url }}api/v1

🔐 Authentication

All API requests require an API key. Create keys at Settings → API Keys.

Option 1: Header (Recommended)

X-API-Key: inv_your_api_key_here

Option 2: Query Parameter

?api_key=inv_your_api_key_here

API Key Permissions

  • read - Can view data (GET requests)
  • write - Can create, update, delete (POST, PUT, DELETE)

Response Format

# Success
{
  "success": true,
  "data": { ... }
}

# Error
{
  "success": false,
  "error": "Error description"
}

🔄 Recurring Invoices API

Manage recurring invoice templates and automate invoice generation. Perfect for use with n8n, Zapier, or cron jobs.

GET /api/v1/recurring

List all recurring invoice templates

GET /api/v1/recurring/{id}

Get a specific recurring invoice with all items

GET /api/v1/recurring/due

Get recurring invoices that are due for generation today or earlier

# Response
{
  "success": true,
  "data": {
    "count": 3,
    "due_invoices": [
      {"id": 1, "customer_name": "Acme Corp", "next_invoice_date": "2026-01-01"}
    ]
  }
}

POST /api/v1/recurring/generate ⭐

Main automation endpoint - Generate ALL due recurring invoices at once

Call this from n8n, Zapier, or a scheduled task to automatically generate invoices.

# Example with curl
curl -X POST "{{ request.host_url }}api/v1/recurring/generate" \
  -H "X-API-Key: inv_your_key" \
  -H "Content-Type: application/json"

# Response
{
  "success": true,
  "data": {
    "generated_count": 3,
    "error_count": 0,
    "generated": [
      {
        "recurring_id": 1,
        "invoice_id": 156,
        "invoice_number": "REC-00156",
        "customer_name": "Acme Corp",
        "total": 1500.00
      }
    ],
    "errors": null
  }
}

POST /api/v1/recurring/{id}/generate

Generate a single recurring invoice immediately (regardless of due date)

POST /api/v1/recurring/{id}/toggle

Pause or resume a recurring invoice

📋 n8n Setup Example

  1. Add a Schedule Trigger node (e.g., daily at 6:00 AM)
  2. Add an HTTP Request node with:
    • Method: POST
    • URL: {{ request.host_url }}api/v1/recurring/generate
    • Header: X-API-Key: your-api-key
  3. Optionally add notification nodes for generated invoices

📱 Mobile App Integration

The receipt_base64 field is ideal for mobile expense apps:

  1. User takes photo of receipt
  2. App converts to base64 (prefix with data:image/jpeg;base64,)
  3. POST to /api/v1/expenses with receipt_base64
  4. Receipt is stored and linked to expense

🔔 Outbound Webhooks

Configure webhooks at Settings → Webhooks to receive notifications when events happen.

Available Events

invoice.created invoice.updated invoice.deleted invoice.sent invoice.paid invoice.partially_paid customer.created customer.updated customer.deleted product.created product.updated payment.received

Webhook Payload

{
  "event": "invoice.paid",
  "timestamp": "2024-01-20T14:30:00Z",
  "webhook_id": "wh_abc123",
  "data": {
    "id": 1,
    "invoice_number": "INV-00001",
    "status": "paid",
    "total": 1800.00,
    ...
  }
}

Headers Sent

Content-Type: application/json
User-Agent: InvoiceManager-Webhook/1.0
X-Webhook-Event: invoice.paid
X-Webhook-Signature: sha256=abc123...

Verifying Signatures (Python)

import hmac, hashlib

def verify_signature(payload, signature, secret):
    expected = 'sha256=' + hmac.new(
        secret.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature)

💻 Code Examples

Python

import requests

API_KEY = "inv_your_key"
BASE = "{{ request.host_url }}api/v1"
headers = {"X-API-Key": API_KEY, "Content-Type": "application/json"}

# Create invoice
invoice = {
    "customer_id": 1,
    "currency": "GBP",
    "tax_rate": 20,
    "items": [
        {"description": "Consulting", "quantity": 10, "unit_price": 150}
    ]
}
response = requests.post(f"{BASE}/invoices", json=invoice, headers=headers)
print(response.json())

JavaScript / Node.js

const axios = require('axios');

const API_KEY = 'inv_your_key';
const BASE = '{{ request.host_url }}api/v1';
const headers = { 'X-API-Key': API_KEY };

// Create invoice
const invoice = {
  customer_id: 1,
  currency: 'GBP',
  tax_rate: 20,
  items: [
    { description: 'Consulting', quantity: 10, unit_price: 150 }
  ]
};

axios.post(`${BASE}/invoices`, invoice, { headers })
  .then(res => console.log(res.data));

PowerShell

$Headers = @{
    "X-API-Key" = "inv_your_key"
    "Content-Type" = "application/json"
}

$Invoice = @{
    customer_id = 1
    currency = "GBP"
    tax_rate = 20
    items = @(
        @{ description = "Consulting"; quantity = 10; unit_price = 150 }
    )
} | ConvertTo-Json -Depth 3

Invoke-RestMethod -Uri "{{ request.host_url }}api/v1/invoices" `
  -Method Post -Headers $Headers -Body $Invoice
