# Changelog

All notable changes to Invoice Manager are documented here.

## [1.0.0] - January 2026

### 🎉 Initial Release

The first stable release of Invoice Manager!

### Added

#### Core Features
- **Invoicing**: Create, edit, and manage professional invoices
- **Customers**: Full customer management with custom fields
- **Products**: Product/service catalog with pricing
- **Payments**: Track payments and partial payments
- **PDF Generation**: Professional PDF invoices with branding

#### User Management
- **Multi-user Support**: Add team members to your account
- **Role-based Access**: Owner, Admin, Accountant, Bookkeeper, Sales, Viewer roles
- **Two-Factor Authentication**: Secure your account with 2FA
- **User Profiles**: Avatars and personal settings

#### Financial Features
- **Multi-Currency**: Support for 20+ currencies
- **Exchange Rates**: Automatic rate updates via CurrencyAPI
- **Tax Management**: Default and customer-specific tax rates
- **Financial Reporting**: Basic reporting dashboard

#### Integration
- **REST API**: Full API access for all resources
- **Webhooks**: Real-time notifications for events
- **Email Integration**: Send invoices via SMTP
- **Import/Export**: CSV import and export

#### Settings & Customization
- **Company Branding**: Logo, colors, custom footer
- **Invoice Templates**: Customizable PDF templates
- **Email Templates**: Customize email content
- **Database Options**: SQLite or MySQL support

### Security
- Password hashing with industry-standard algorithms
- Session management
- API key authentication
- Input validation and sanitization

## Version Numbering

We follow [Semantic Versioning](https://semver.org/):

- **MAJOR**: Incompatible API changes
- **MINOR**: New features (backwards compatible)
- **PATCH**: Bug fixes (backwards compatible)
