## What is Invoice Manager?

Invoice Manager is a professional invoicing solution designed for small businesses, freelancers, and consultants. It provides everything you need to:

- ✅ Create and send professional invoices
- ✅ Manage customers and products
- ✅ Track payments and outstanding balances
- ✅ Support multiple currencies
- ✅ Collaborate with your team
- ✅ Integrate with other systems via API

## Key Features

### 📄 Professional Invoices
Create beautiful, professional invoices with your branding. Export to PDF or send directly via email.

### 💱 Multi-Currency Support
Invoice clients in their preferred currency with automatic exchange rate updates.

### 👥 Team Management
Add team members with role-based access control. Keep your data secure while collaborating.

### 🔌 API & Webhooks
Full REST API for integrations. Receive real-time notifications via webhooks.

### 📧 Email Integration
Send invoices and payment reminders directly from the application.
